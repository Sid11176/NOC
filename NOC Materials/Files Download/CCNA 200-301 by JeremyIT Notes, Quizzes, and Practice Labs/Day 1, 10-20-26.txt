NOTES:
Host-based firewalls - are software applications that filter traffic entering and exiting a host machine, like a PC.

A switch - provides connectivity to hosts within the same LAN. It also has many network interfaces for end hosts to connect to. Routers have fewer network interfaces than switches.

Next-Generation Firewall - A firewall which combines a traditional firewall with more advanced filtering functionalities

Client - is a device that accesses a service made available by a server.

A computer network is a digital telecommunications network which allows NODES to share resources.

Servers  /  clients - are also known as 'end hosts' or 'endpoints'.

Firewall - monitors and controls network traffic based on configured rules.

Server - is a device that provides functions or services for clients.

What kind of network device is a Cisco ASA?  -- Firewall

What kind of network device is a Cisco ISR?  -- Router


What kind of network device is a Cisco Firepower? -- Firewall




1) Your company wants to purchase some network hardware to which they can plug

a) A router
